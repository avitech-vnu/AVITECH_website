# AVITECH_website

## Guide for Editing Your Research

1. **Fork the repository** to your own GitHub account.

2. **Each member of the AVITECH research group is responsible for maintaining their own `.bib` file.**
   - If your `.bib` file already exists, edit the existing file.
   - **If you do not have a `.bib` file yet, create a new one** in the designated directory, following the existing naming convention (e.g., `YourName.bib`).

3. **Edit your `.bib` file** using either of the following methods:
   - **Offline:** Clone your forked repository to your local machine and edit your `.bib` file.
   - **Online:** Create or edit your `.bib` file directly through the GitHub web interface.

4. **Submit your changes:** Save your changes and create a Pull Request to the main repository.

5. **Review and merge:** The admin is responsible for reviewing and merging the latest `.bib` files from all members.



## Guide for Editing your Profile

Follow the steps below to display your personal profile on the AVITECH website.

### Step 0: Important Notes

- Only modify sections marked with `<!-- === [EDIT HERE] === -->`.
- Keep the existing HTML structure unchanged to avoid display issues on WordPress.
- **Please make sure your profile photo meets the required specifications before uploading.**

### Step 1: Prepare and Upload Your Profile Photo

**Your profile photo MUST meet ALL of the following requirements:**

- **Aspect ratio: 1:1 (Square image)** — Width and height must be equal.
- **Format: PNG**
- **File name:** Must exactly match your folder name (e.g., `DoHaiSon.png`).
- **Directory:** Upload to `profiles/YourName/`.

<ins>Important:</ins> **Do NOT upload rectangular photos (e.g., 3:4, 4:3, or 16:9).** If your original photo is not square, please crop or resize it to a 1:1 ratio before uploading.

### Step 2: Edit Your Profile Information

Edit the following two files in `profiles/YourName/`:

- `YourName_vn.html` — Vietnamese profile.
- `YourName_en.html` — English profile.

Update the following information:

- Job title and affiliation.
- Short biography.
- Personal website and email (optional).

### Step 3: Review Your Profile

Before submitting your changes, please check that:

- [ ] Your profile photo is a square image (1:1 ratio).
- [ ] Your photo is in PNG format.
- [ ] Your photo filename matches your folder name.
- [ ] Both Vietnamese and English profile files have been updated.
- [ ] The existing HTML structure has been preserved.
